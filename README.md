# Project-04-
Personal Portfolio Website

About the Project

This project is a personal portfolio website created using HTML, CSS, and JavaScript. It presents personal information, skills, projects, and contact details in an organized and user-friendly layout.

The website includes light and dark themes to provide different visual experiences.

<h2>Features<h2>

1-Responsive navigation bar

2-Personal introduction section

3-Projects and skills sections

4-Contact form

5-Light and dark theme switching

6-Social media links
